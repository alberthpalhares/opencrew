# Busca de execuções

Use `node _opencrew/core/scripts/buscar.mjs "{termo}"` na raiz do projeto. Acrescente `--crew "{nome}"` ou `--run "{id}"` quando solicitado. A regra de nome seguro do runner vale para os argumentos. Mostre os caminhos e a situação que o script retornou. A consulta não grava arquivos.
